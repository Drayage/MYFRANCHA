# 🏷️ 프차야 — 프랜차이즈 상표 분쟁 카드게임

> "상표가 실제로 이동하며 뺏기는, 5라운드 기반 실시간 카드 전략 게임"

두 공동 창업자 **갑(A)** / **을(B)** 이 프랜차이즈 브랜드(상표 3개)를 두고 상표권을
쟁탈하는 1:1 카드 전략 게임입니다. 이 게임의 핵심은 점수가 아니라 **상표가 실제로
이동하며 뺏기는 시각적 전쟁**입니다 — 모든 소유권 변경은 곡선 이동·착지 바운스·충돌
흔들림 애니메이션으로 표현됩니다.

## 🎮 플레이 모드
- 🤖 **AI 대전** — 휴리스틱 AI(을)와 대결
- 👥 **로컬 패스앤플레이** — 한 기기에서 번갈아(가림막 화면 제공)

## ✨ 옵션 (시작 화면 토글)
- 📖 **튜토리얼 켜기** — 켜면 게임 시작 시 코치마크 가이드 노출(기본 꺼짐)
- 🧬 **상표 능력 모드** — 맹한커피(첫 카드 상대 카드 확인)·햄부기퀸(선플 토큰 유지)·염라떡볶이
- 🎭 **연극모드** — 카드 발동 시 갑/을이 유쾌한 대사를 주고받음

## 🆕 추가 기능
- 🃏 **세트 동시 공개** — 이번 세트 카드를 뒷면으로 깔고 한꺼번에 뒤집어 공개한 뒤, 턴 순서대로
  결과를 순차 처리. 소송뭉개기는 **같은 턴 상대 카드**를 자동 무효화("무효" 스탬프).
- 📖 **초보자 온보딩** — 튜토리얼 코치마크, 카드 툴팁, 유효 대상 하이라이트, 단계 배너, 규칙 도움말
- ▶ **리플레이** — 한 판의 모든 이동을 애니메이션과 함께 재생(재생/일시정지/스텝/속도)

## 📐 규칙 요약
- **승리**: 상표 3개 모두 소유 시 즉시 승리. 5라운드 종료 시 상표가 더 많은 쪽 승리
  (동점 → 라운드 토큰 많은 쪽 → 완전 동점이면 마지막 토큰 보유자).
- **한 라운드 = 3세트**: 1차(1장) → 2차(2장) → 3차(2장). **각 세트 종료마다 선플레이어
  토큰 교대**(라운드당 3번).
- **라운드 토큰**: 한 라운드 중 상표 2개를 먼저 확보하면 1개 획득(누적).
- **카드 4종**: 출원(중앙→내 영역) / 사실관계증명(상대→내 영역) /
  불사용취소심판(상대→중앙) / 소송뭉개기(같은 턴 상대 카드 무효).
- **손패**: 매 라운드 고정 5장 — 출원 2 / 사실관계증명 1 / 불사용취소심판 1 / 소송뭉개기 1.

## ▶ 실행 방법
ES 모듈을 사용하므로 `file://` 직접 열기는 동작하지 않습니다. 정적 서버로 실행하세요:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🚀 배포 (GitHub Pages)
저장소 **Settings → Pages** 에서 브랜치를 선택해 배포하면 루트에서 그대로 서비스됩니다
(모든 경로는 상대경로). PWA(매니페스트 + 서비스워커)로 설치/오프라인 플레이를 지원합니다.
